# TASK-0048: Implement Dashboard Layout with Sidebar Navigation

## Objective
Build the main dashboard layout with responsive sidebar navigation, header, and content area.

## Context
The dashboard layout provides consistent navigation across all admin pages. It must be responsive and support dark mode. See EPICS.md Epic-09.

## Acceptance Criteria
- [ ] `frontend/src/components/layout/DashboardLayout.tsx` — main layout
  - Sidebar with navigation links: Dashboard, Providers, API Keys, Analytics, Settings
  - Top header with: org name, user avatar/dropdown, dark mode toggle
  - Collapsible sidebar (hamburger on mobile)
  - Active route highlighting in sidebar
- [ ] `frontend/src/components/layout/Sidebar.tsx` — sidebar component
  - Navigation items with icons (Lucide React)
  - Section grouping: Manage (Providers, Keys), Monitor (Analytics), Configure (Settings)
  - Responsive: hidden on mobile, slide-out drawer
- [ ] `frontend/src/components/layout/Header.tsx` — top header
  - Organization name/logo
  - User menu: profile, settings, logout
  - Dark mode toggle button
  - Notification bell (placeholder)
- [ ] `frontend/src/App.tsx` — route definitions with layout wrapper
  - `/admin/dashboard` → Dashboard page
  - `/admin/providers` → Providers page
  - `/admin/keys` → API Keys page
  - `/admin/analytics` → Analytics page
  - `/admin/settings` → Settings page
- [ ] Dark mode support: `dark` class on html element, Tailwind `dark:` variants
- [ ] RBAC in UI: viewer role sees read-only, admin cannot delete org

## Files Affected
- `frontend/src/components/layout/DashboardLayout.tsx` — new

- `frontend/src/components/layout/Header.tsx` — new

## Technical Notes
- Use shadcn/ui Sidebar component or build custom with Tailwind
- Use `lucide-react` for icons
- Dark mode: `useTheme` hook toggling `dark` class on document.documentElement
- Store theme preference in localStorage
- Use `react-router-dom` v6 with `Outlet` for nested routes
- RBAC: conditionally render edit buttons based on user.role

## Test Requirements
- Sidebar renders all navigation links
- Active route highlighted correctly
- Dark mode toggle works and persists
- Mobile: sidebar hidden, hamburger opens drawer
- Viewer role: no edit/delete buttons visible
