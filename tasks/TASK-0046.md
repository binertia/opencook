# TASK-0046: Initialize React Dashboard with Vite, TypeScript, and shadcn/ui

## Objective
Set up the React/TypeScript frontend project with Vite build tooling, shadcn/ui component library, Tailwind CSS, and essential dependencies.

## Context
The admin dashboard is a React SPA served as static files. It uses shadcn/ui for accessible components, Tailwind for styling, and TanStack Query for server state. See TECH_STACK.md sections 1.2, 2.2 and EPICS.md Epic-09.

## Acceptance Criteria
- [ ] `frontend/package.json` with dependencies: react, typescript, vite, tailwindcss, @radix-ui/*, tanstack-query, zustand, react-router-dom, recharts, ky, zod, react-hook-form
- [ ] `frontend/vite.config.ts` configured with proxy to backend API
- [ ] `frontend/tsconfig.json` with strict mode
- [ ] `frontend/tailwind.config.js` with shadcn/ui theme configuration
- [ ] shadcn/ui initialized with `components.json`
- [ ] `frontend/src/main.tsx` — app entry point with React.StrictMode
- [ ] `frontend/src/App.tsx` — root component with router
- [ ] `frontend/src/index.css` — Tailwind directives + base styles
- [ ] `npm run dev` starts dev server on port 5173
- [ ] `npm run build` produces static files in `frontend/dist/`

## Technical Notes
- Use `npx shadcn-ui@latest init` for initialization
- Install shadcn base components: button, card, input, label, table, dialog, dropdown-menu, select, tabs, toast
- Vite proxy: `/api` → `http://localhost:8080`
- Tailwind theme: extend with CSS variables for shadcn theming
- Use `pnpm` as package manager (faster, disk efficient)
