# TASK-0047: Implement API Client, Auth Hooks, and Login Page

## Objective
Build the typed API client, authentication hooks, and login page for the admin dashboard.

## Context
The dashboard communicates with the gateway via REST APIs. Auth uses JWT tokens stored in httpOnly cookies. See API_SPEC.md section 4.2 and EPICS.md Epic-09.

## Acceptance Criteria
- [ ] `frontend/src/lib/api.ts` — typed API client using `ky`
  - Base URL from env var or `/api`
  - Automatic 401 handling → redirect to login
  - Request/response interceptors for auth and error handling
- [ ] `frontend/src/hooks/useAuth.ts` — auth hook
  - `login(email, password)` → POST /api/v1/auth/login
  - `logout()` → POST /api/v1/auth/logout + clear state
  - `refresh()` → POST /api/v1/auth/refresh
  - `user` → current user with permissions
- [ ] `frontend/src/hooks/useApi.ts` — data fetching hook wrapping TanStack Query
- [ ] `frontend/src/pages/Login.tsx` — login page
  - Email/password form with validation (Zod schema)
  - Error handling (invalid credentials, account locked)
  - Redirect to dashboard on success
- [ ] `frontend/src/store/authStore.ts` — Zustand auth store
  - Stores user, tokens, login/logout actions

## Files Affected
- `frontend/src/lib/api.ts` — API client
- `frontend/src/hooks/useAuth.ts` — auth hook
- `frontend/src/hooks/useApi.ts` — data fetching hook
- `frontend/src/pages/Login.tsx` — login page
- `frontend/src/store/authStore.ts` — auth store

## Dependencies
- TASK-0046 (React project setup)
- TASK-0013 (JWT session auth backend)

## Technical Notes
- Use `ky` instead of axios (smaller, fetch-based)
- Use `zustand` for client state (auth store)
- Use `@tanstack/react-query` for server state (caching, refetching)
- Form validation with `zod` + `react-hook-form`
- httpOnly cookies set by backend — frontend just makes requests
- On 401: redirect to /login with return URL

## Test Requirements
- Login form validates email format and non-empty password
- Successful login stores user data
- Invalid credentials show error message
- Logout clears auth state and redirects to login
