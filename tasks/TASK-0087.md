# TASK-0087: Create Production Dockerfile and Docker Compose

## Objective
Build multi-stage production Dockerfile for the backend and Docker Compose for production deployment.

## Context
The production container must be minimal, secure, and efficient. Uses distroless or Alpine base. See EPICS.md Epic-18.

## Acceptance Criteria
- [x] `docker/Dockerfile.backend` — multi-stage production build
  - Stage 1: `cargo chef` planner
  - Stage 2: Frontend build (`node:22-bookworm`)
  - Stage 3: `cargo chef cook` + `cargo build --release`
  - Stage 4: Runtime stage (`gcr.io/distroless/cc-debian12:nonroot`)
  - Frontend static files copied into image at `./frontend/dist`
  - Non-root user (`nonroot` in distroless)
  - Single binary: `gateway-api`
  - Exposes port 8080 (API) and 9090 (metrics)
  - `HEALTHCHECK` configured
- [x] `docker-compose.yml` — production orchestration
  - Services: gateway, postgres, redis, nginx (reverse proxy)
  - Named volumes for postgres and redis data
  - Environment variables from `.env` / shell
  - Health checks for all services
  - Restart policy: `unless-stopped`
- [x] `nginx/nginx.conf` — reverse proxy config
  - SSL termination ready (cert mounts)
  - Rate limiting per IP (`10r/s` API, `5r/m` auth)
  - Request body size limit (`10m`)
  - Upstream to `gateway:8080`
  - Static file serving for `/admin/assets/*` with `Cache-Control: max-age=31536000`
  - SPA fallback for `/admin` routes
- [x] `.dockerignore` — excludes target, node_modules, .git, docs, data, tests

## Files Affected
- `docker/Dockerfile.backend` — production backend image
- `docker-compose.yml` — production orchestration
- `nginx/nginx.conf` — reverse proxy
- `.dockerignore` — build context exclusions

## Dependencies
- TASK-0001 (workspace structure)
- TASK-0055 (static file serving)

## Technical Notes
- `cargo chef` provides Docker layer caching: dependency cook is cached until `Cargo.toml` changes
- Distroless runtime image has no shell, reducing attack surface
- Nginx handles SSL termination, rate limiting, and static asset caching
- Gateway binary serves API routes and SPA fallback for `/admin`
- Build command: `docker build -f docker/Dockerfile.backend -t gateway:latest .`
- Run command: `docker compose up -d`
