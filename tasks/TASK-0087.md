# TASK-0087: Create Production Dockerfile and Docker Compose

## Objective
Build multi-stage production Dockerfile for the backend and Docker Compose for production deployment.

## Context
The production container must be minimal, secure, and efficient. Uses distroless or Alpine base. See EPICS.md Epic-18.

## Acceptance Criteria
- [ ] `docker/Dockerfile.backend` — multi-stage production build
  - Stage 1: Rust build stage with cargo chef caching
  - Stage 2: Runtime stage (debian:bookworm-slim or distroless/cc)
  - Frontend static files copied into image
  - Non-root user (uid 1000)
  - Single binary: `gateway-api`
  - Exposes port 8080 (API) and 9090 (metrics)
- [ ] `docker-compose.yml` — production orchestration
  - Services: gateway, postgres, redis, nginx (reverse proxy)
  - Named volumes for postgres and redis data
  - Environment file: `.env.production`
  - Health checks for all services
  - Restart policy: unless-stopped
- [ ] `nginx/nginx.conf` — reverse proxy config
  - SSL termination (if not using Rustls)
  - Rate limiting per IP
  - Request body size limit (10MB)
  - Upstream to gateway:8080
  - Static file serving for `/admin/assets/*` with caching headers
- [ ] Image size < 100MB

## Files Affected
- `docker/Dockerfile.backend` — production backend image
- `docker-compose.yml` — production orchestration
- `nginx/nginx.conf` — reverse proxy
- `.dockerignore` — build context exclusions

## Dependencies
- TASK-0001 (workspace structure)
- TASK-0055 (static file serving)

## Technical Notes
- Use `cargo chef` for Docker layer caching of dependencies
- Build: `cargo chef prepare` → `cargo chef cook` → `cargo build --release`
- Use `gcr.io/distroless/cc-debian12` for minimal runtime image
- Copy `frontend/dist/` to `/app/static/` in image
- Set `APP_ENV=production` in container
- Health check: `HEALTHCHECK --interval=30s --timeout=5s CMD curl -f http://localhost:8080/health || exit 1`

## Test Requirements
- `docker build -f docker/Dockerfile.backend -t gateway:latest .` succeeds
- Image size < 100MB
- Container starts and responds to `/health`
- `docker compose up -d` starts all services successfully
- Nginx proxies to gateway correctly
