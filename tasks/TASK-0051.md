# TASK-0051: Implement Dashboard Overview Page with KPI Cards

## Objective
Build the dashboard overview page showing KPI cards, recent activity, and quick stats.

## Context
The overview page is the first thing users see after logging in. It shows key metrics at a glance. See EPICS.md Epic-09.

## Acceptance Criteria
- [ ] `frontend/src/pages/DashboardPage.tsx` — overview page
  - 4 KPI cards: Total Requests (today), Total Cost (today), Cache Hit Rate, Avg Latency
  - Time range selector: Today, Last 7 Days, Last 30 Days
  - Recent requests table: last 10 requests with status
  - Active providers list with health indicators
  - Quick actions: Create API Key, Add Provider (links)
- [ ] `frontend/src/hooks/useDashboard.ts` — dashboard data hook
  - Aggregates data from usage API for KPI cards
  - Fetches recent requests, active providers
- [ ] `frontend/src/components/dashboard/KpiCard.tsx` — KPI card component
  - Title, value, change indicator (up/down from previous period)
  - Icon, color-coded border
- [ ] `frontend/src/components/dashboard/RecentRequests.tsx` — recent requests table
  - Truncated columns: time, model, status, tokens, cost, latency
- [ ] Loading skeletons for all data sections
- [ ] Error states with retry buttons

## Technical Notes
- Use shadcn/ui `Card` component for KPI cards
- Use `recharts` for sparkline mini-charts in KPI cards (optional)
- Use `@tanstack/react-query` with `staleTime: 60_000` (1 min) for dashboard data
- Skeleton loading: shadcn/ui `Skeleton` component
- Format numbers: `Intl.NumberFormat` for costs, compact notation for large numbers
- Color coding: green for good, red for errors, yellow for warnings

## Test Requirements
- KPI cards render with correct data
- Time range change updates all KPIs
- Recent requests table shows last 10 requests
- Loading skeleton shown while fetching
- Error state with retry button on API failure
