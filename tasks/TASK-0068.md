# TASK-0068: Implement Vector Similarity Cache with pgvector

## Objective
Build the semantic cache that stores query embeddings in pgvector and finds similar previous queries by cosine similarity.

## Context
Semantic cache uses vector similarity to find equivalent requests even with different wording. Uses pgvector extension with HNSW indexing. Target: 20% additional cache hits on top of exact cache. See CACHE.md section 3 and EPICS.md Epic-14.

## Acceptance Criteria
- [ ] `crates/gateway-cache/src/semantic.rs` — semantic cache module
  - `SemanticCache` struct with pgvector-backed storage
  - `store_embedding(key, embedding, response, ttl)` — stores response with embedding
  - `find_similar(embedding, similarity_threshold) -> Option<CachedResponse>` — finds similar query
  - `similarity_threshold`: 0.97 cosine similarity (configurable)
- [ ] `query_embeddings` table (migration):
  - `id`, `org_id`, `model`, `embedding vector(768)`, `response_hash`, `created_at`, `expires_at`
  - HNSW index on embedding column with `cosine` distance
  - Partial index: `WHERE expires_at > NOW()`
- [ ] Integration with embedding model:
  - `text-embedding-3-small` for caching (OpenAI, 1536 dims)
  - Async embedding generation on cache miss
  - Configurable: `GATEWAY_CACHE_EMBEDDING_MODEL` env var
- [ ] Similarity search query: uses HNSW index, single round-trip
  - `SELECT response_hash FROM query_embeddings WHERE org_id = $1 AND model = $2 ORDER BY embedding <=> $3 LIMIT 1`

## Technical Notes
- Use `pgvector` Rust crate for vector operations
- HNSW index: `CREATE INDEX idx_query_embeddings_hnsw ON query_embeddings USING hnsw (embedding vector_cosine_ops)`
- Embedding dimensions: configurable (default 1536 for OpenAI)
- Limit embedding text to first 8K characters
- Expired entries cleaned by background task
- Store actual response in Redis, only embedding + response_hash in pgvector

## Test Requirements
- Unit test: similar queries find each other (cosine sim > 0.97)
- Unit test: different queries do not match (cosine sim < 0.97)
- Integration test: HNSW index used for similarity search (EXPLAIN)
- Integration test: expired entries not returned
- Performance test: similarity search < 10ms
