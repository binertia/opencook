# TASK-0059: Implement Request Logs Viewer with Filtering

## Objective
Build the request logs page with paginated table, filtering by model/provider/status, and request detail view.

## Context
Request logs provide visibility into all AI API traffic. Admins need to search, filter, and inspect individual requests. See EPICS.md Epic-09 (foundation includes request logs viewer) and API_SPEC.md section 3.7.

## Acceptance Criteria
- [ ] `frontend/src/pages/LogsPage.tsx` — request logs page
  - Table: timestamp, trace_id, model, provider, status, tokens, cost, latency, cache hit
  - Filters: date range picker, model dropdown, provider dropdown, status dropdown
  - Search by trace_id
  - Pagination (server-side): limit 20, offset-based
  - Sort by timestamp (default desc), cost, latency
- [ ] `frontend/src/components/logs/RequestDetail.tsx` — detail drawer/modal
  - Full request: model, messages (truncated), parameters
  - Full response: content (truncated), finish_reason, usage
  - Metadata: provider, routing rule, cache status, latency breakdown
  - Copy trace_id button
- [ ] `frontend/src/hooks/useRequestLogs.ts` — logs data hook
  - `useRequestLogs(org_id, filters)` → GET /api/v1/organizations/{org_id}/requests
  - `useRequestDetail(trace_id)` → single request detail
- [ ] Auto-refresh every 30 seconds (optional toggle)
- [ ] Export to CSV button (frontend CSV generation)

## Files Affected
- `frontend/src/pages/LogsPage.tsx` — new

- `frontend/src/hooks/useRequestLogs.ts` — new

## Technical Notes
- Use shadcn/ui `Table` with sorting and pagination
- Date range: use `date-fns` for formatting and range calculations
- Filters: `useSearchParams` for URL-synced filter state
- Request detail: `Sheet` (slide-out drawer) from shadcn/ui
- Messages in detail view: truncated to 500 chars with expand toggle
- CSV export: generate in browser, trigger download
- Color coding: status (green=success, red=error, blue=cached)
