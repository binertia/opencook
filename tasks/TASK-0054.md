# TASK-0054: Implement Provider Detail Page with Model Management

## Objective
Build the provider detail page showing full configuration, model list with pricing, and health history.

## Context
Admins need detailed view of each provider for debugging and fine-tuning. See EPICS.md Epic-10.

## Acceptance Criteria
- [ ] `frontend/src/pages/providers/ProviderDetailPage.tsx` — detail page
  - Provider info card: name, kind, base URL, status, weight, priority
  - Model list table: model ID, name, status, input cost, output cost, capabilities
  - Model actions: enable/disable toggle
  - Health history chart (last 24h): line chart of latency and error rate
  - Recent errors table: timestamp, error message, status code
  - Edit button → opens EditProviderModal
  - Delete button with confirmation (blocked if referenced by routing rules)
- [ ] `frontend/src/components/providers/ModelList.tsx` — model list component
  - Toggle switch for enable/disable per model
  - Inline pricing edit (optional — can defer to settings)
- [ ] `frontend/src/components/providers/HealthChart.tsx` — health history chart
  - Uses `recharts` LineChart with two lines: latency (ms), error rate (%)
  - Time range: last 24h (from health history API)

## Files Affected
- `frontend/src/pages/providers/ProviderDetailPage.tsx` — new
- `frontend/src/components/providers/ModelList.tsx` — new
- `frontend/src/components/providers/HealthChart.tsx` — new

## Dependencies
- TASK-0053 (edit provider modal)
- TASK-0047 (API client)

## Technical Notes
- Route: `/admin/providers/:providerId`
- Use `recharts` `LineChart` with two Y-axes (latency left, error rate right)
- Health data from `GET /api/v1/providers/{id}/health-history`
- Model enable/disable: PATCH request to backend
- Delete check: show warning if provider referenced by routing rules
- Use `useParams` from react-router-dom for provider ID

## Test Requirements
- Detail page loads provider data correctly
- Model toggle sends PATCH request
- Health chart renders with data points
- Delete blocked for provider in use by routing rules
- Delete confirmation for unused provider
