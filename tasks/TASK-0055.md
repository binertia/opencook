# TASK-0055: Serve Dashboard as Static Files from Gateway Container

## Objective
Configure the Rust backend to serve the built React SPA as static files at `/admin` and handle client-side routing.

## Context
The dashboard is a single-page application that needs to be served from the same container as the gateway API. All non-API routes should serve `index.html` for client-side routing. See ARCHITECTURE.md section 3.2.8 and EPICS.md Epic-09.

## Acceptance Criteria
- [ ] `crates/gateway-api/src/static_files.rs` — static file serving
  - Serves files from `frontend/dist/` directory at `/admin/*`
  - `GET /admin` → serves `frontend/dist/index.html`
  - `GET /admin/*` (any path) → serves `frontend/dist/index.html` (SPA routing)
  - `GET /admin/assets/*` → serves actual asset files with correct MIME types
- [ ] `crates/gateway-api/src/router.rs` — updated with static file routes
  - `/admin` and `/admin/*` handled by static file service
  - `/api/v1/*` handled by API routes
  - `/v1/*` handled by LLM API routes
  - `/health` and `/ready` handled directly
- [ ] Dockerfile copies `frontend/dist/` into container image
- [ ] `index.html` includes `<base href="/admin">` for correct asset loading
- [ ] Dev mode: skip static file serving (use Vite dev server)

## Files Affected
- `crates/gateway-api/src/static_files.rs` — new
- `crates/gateway-api/src/router.rs` — updated
- `docker/Dockerfile.backend` — copy frontend/dist

## Technical Notes
- Use `tower_http::services::ServeDir` for static files
- SPA fallback: if file not found, serve `index.html`
- Use `tower_http::services::ServeFile` for index.html
- Check `APP_ENV` env var: if "development", skip static file routes
- Gzip compression for static assets via `tower_http::compression`
- Cache headers for asset files: `Cache-Control: max-age=31536000` (1 year)

## Test Requirements
- `GET /admin` returns `index.html` with 200
- `GET /admin/providers` returns `index.html` (SPA fallback)
- `GET /admin/assets/main.js` returns actual JS file
- API routes (`/api/v1/...`) still work correctly
