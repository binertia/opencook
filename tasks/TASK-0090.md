# TASK-0090: Create Terraform/Helm Infrastructure Definition

## Objective
Provide infrastructure-as-code definitions for deploying the gateway on AWS with managed PostgreSQL and Redis.

## Context
Infrastructure should be reproducible and version-controlled. Terraform modules define the required AWS resources. See EPICS.md Epic-18.

## Acceptance Criteria
- [x] `terraform/main.tf` — Terraform configuration (AWS example)
  - EKS cluster with managed node group
  - RDS PostgreSQL 16 (db.t3.medium, multi-AZ)
  - ElastiCache Redis 7 (cache.t3.micro)
  - S3 bucket for static assets
  - VPC with private/public subnets across 2 AZs
  - Security groups: gateway ↔ postgres, gateway ↔ redis
- [x] `terraform/variables.tf` — configurable variables
  - region, instance sizes, replica counts
  - database password (sensitive)
- [x] `terraform/outputs.tf` — useful outputs
  - cluster endpoint, database endpoint, Redis endpoint
- [x] `helm/gateway/` — Helm chart
  - `Chart.yaml` — chart metadata
  - `values.yaml` — default values
  - `templates/` — Kubernetes manifests as templates
  - Configurable: replicas, resources, env vars, secrets
- [x] `helm/gateway/values-production.yaml` — production overrides
