# TASK-0056: Implement API Key List Page with Status and Usage

## Objective
Build the API key management page showing all keys with prefix, name, status, last used, and usage count.

## Context
Admins manage gateway API keys through the dashboard. The list shows key metadata without exposing full keys. See EPICS.md Epic-11.

## Acceptance Criteria
- [x] `frontend/src/pages/keys/KeysPage.tsx` — API key list page
  - Table: key prefix, name, status (active/revoked/expired), scopes, last used, created
  - Usage column: request count and estimated cost for current period
  - Status filter: All, Active, Revoked, Expired
  - Search by name or prefix
  - Each row has: revoke button (if active), edit link
  - "Create Key" button opens create modal
- [x] `frontend/src/hooks/useApiKeys.ts` — API keys data hook
  - `useApiKeys()` → GET /v1/api-keys
  - `useKeyUsage(range)` → GET /v1/analytics/keys

## Files Affected
- `frontend/src/pages/ApiKeys.tsx` — enhanced with filters, search, usage, edit
- `frontend/src/hooks/useApiKeys.ts` — added `useKeyUsage` hook and types

## Dependencies
- TASK-0048 (dashboard layout)
- TASK-0014 (API key generation backend)
- TASK-0047 (API client)

## Technical Notes
- Uses shadcn/ui `Table` with client-side filtering
- Status badge: green (active), red (revoked), gray (expired)
- Usage fetched from `/v1/analytics/keys` with 30d range
- Format: relative time for "last used", locale date for "created"
- `key_prefix` displayed with tooltip showing full prefix
- Edit opens dialog to rename key
- Search filters by name or prefix (case-insensitive)
