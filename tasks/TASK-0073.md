# TASK-0073: Implement Webhook Event Publisher and Retry Logic

## Objective
Build the event publisher that triggers webhook deliveries and the retry mechanism with exponential backoff.

## Context
When events occur (quota warning, provider error, etc.), the publisher sends webhooks asynchronously with retries. See EPICS.md Epic-15.

## Acceptance Criteria
- [ ] `crates/gateway-core/src/webhook_publisher.rs` — event publisher
  - `publish(event: WebhookEvent)` — queues webhook for delivery
  - Background worker: processes queue with `tokio::spawn`
  - Event types: request.completed, request.failed, quota.warning, quota.exceeded, provider.error, provider.recovered
- [ ] Delivery flow:
  1. Insert delivery record (status: queued)
  2. POST to webhook URL with signed payload
  3. On 2xx: mark completed, increment success counter
  4. On non-2xx or timeout: retry with exponential backoff (5s, 25s, 125s)
  5. After 3 failures: mark failed, increment failure counter
- [ ] 90% of webhooks delivered within 10 seconds
- [ ] Each delivery attempt logged with request/response preview (1KB truncated)
- [ ] Failed deliveries visible in admin UI with retry option

## Files Affected
- `crates/gateway-core/src/webhook_publisher.rs` — new
- `crates/gateway-core/src/lib.rs` — module export
- `crates/gateway-db/src/models.rs` — WebhookEvent enum

## Dependencies
- TASK-0072 (webhook CRUD and delivery repo)
- TASK-0006 (Redis for queue or DB-based queue)

## Technical Notes
- Use `tokio::sync::mpsc::channel` for internal queue (bounded, 1000)
- Use `tokio::task::JoinSet` for concurrent deliveries
- Limit concurrent deliveries per org (max 5)
- Payload truncated at 1KB for delivery log
- Content-Type: `application/json`
- User-Agent: `AI-Gateway-Webhook/1.0`
- Store response body preview (first 200 chars) on each attempt

## Test Requirements

- Integration test: webhook delivered to HTTP endpoint (mock server)
- Integration test: retry on 500, success on 2nd attempt
- Integration test: 3 failures → marked failed
- Performance test: 90% delivered within 10s (mock server)
