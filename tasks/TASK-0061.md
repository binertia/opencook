# TASK-0061: Implement Token Usage and Cache Analytics Pages

## Objective
Build token usage visualization and cache analytics pages showing hit rates, cost savings, and cache size.

## Context
Token usage and cache analytics help users optimize their AI spend. See EPICS.md Epic-12.

## Acceptance Criteria
- [ ] Token usage page:
  - Input vs output token distribution (stacked bar chart)
  - Token usage over time (area chart)
  - Tokens by model (horizontal bar)
  - Average tokens per request KPI
- [ ] Cache analytics page:
  - Exact hit rate gauge/meter
  - Cost saved from cache (estimated USD)
  - Cache hit/miss over time (stacked area)
  - Top cached models table: model, hit rate, cost saved
  - Cache size estimate (entry count)
- [ ] `frontend/src/pages/analytics/TokenUsagePage.tsx` — token usage
- [ ] `frontend/src/pages/analytics/CacheAnalyticsPage.tsx` — cache analytics
- [ ] Export buttons on every chart: CSV and JSON

## Files Affected
- `frontend/src/pages/analytics/TokenUsagePage.tsx` — new
- `frontend/src/pages/analytics/CacheAnalyticsPage.tsx` — new
- `frontend/src/components/analytics/TokenDistributionChart.tsx` — new
- `frontend/src/components/analytics/CacheHitRateChart.tsx` — new

## Dependencies
- TASK-0060 (analytics overview page)
- TASK-0040 (cache metrics backend)

## Technical Notes
- Token charts: use `recharts` BarChart with stacked bars
- Cache hit rate: percentage with color (green > 20%, yellow 10-20%, red < 10%)
- Cost saved: calculated as `sum(cached_request_cost)` from usage records
- Export: generate CSV/JSON in browser, trigger download via anchor tag
- Use `useAnalytics` hook with different `group_by` parameters

## Test Requirements
- Token distribution chart renders correctly
- Cache hit rate shows correct percentage
- Export generates valid CSV/JSON files
- Data accuracy verified against backend
