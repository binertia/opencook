# TASK-0061: Implement Token Usage and Cache Analytics Pages

## Objective
Build token usage visualization and cache analytics pages showing hit rates, cost savings, and cache size.

## Context
Token usage and cache analytics help users optimize their AI spend. See EPICS.md Epic-12.

## Acceptance Criteria
- [x] Token usage page (`frontend/src/pages/analytics/TokenUsagePage.tsx`):
  - Input vs output token distribution (stacked bar chart)
  - Token usage over time (area chart)
  - Tokens by model (horizontal stacked bar chart + detail list)
  - Average tokens per request KPI
  - CSV and JSON export buttons
- [x] Cache analytics page (`frontend/src/pages/analytics/CacheAnalyticsPage.tsx`):
  - Exact hit rate gauge/meter with color coding (green >20%, yellow 10-20%, red <10%)
  - Cost saved from cache (estimated USD)
  - Cache hit/miss over time (stacked area chart)
  - Top cached models table: model, hit rate, cost saved
  - Cache size estimate (entry count) via `useCacheStats` hook
  - CSV and JSON export buttons
- [x] Backend: `entry_count` added to `CacheStatsResponse` via `CacheMetaRepo::get_entry_count`
- [x] Frontend: `useCacheStats` hook created for `/api/v1/cache/stats` endpoint

## Technical Notes
- Token charts: use `recharts` BarChart with `layout="vertical"` for horizontal bars
- Cache hit rate: percentage with color (green > 20%, yellow 10-20%, red < 10%)
- Cost saved: calculated as `sum(cached_request_cost)` from usage records
- Export: generate CSV/JSON in browser, trigger download via anchor tag
- Cache entry count: queried from `cache_metadata` table (non-deleted entries)

## Test Requirements
- Token distribution chart renders correctly
- Cache hit rate shows correct percentage
- Export generates valid CSV/JSON files
- Data accuracy verified against backend
