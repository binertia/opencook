# TASK-0017: Implement Account Lockout and Password Reset

## Objective
Implement account lockout after 5 failed login attempts (30-minute lock) and secure password reset via token-based email flow.

## Context
Security controls for dashboard authentication. Account lockout prevents brute force. Password reset uses secure tokens sent via configurable SMTP. See AUTH.md sections 3.4 and 7.

## Acceptance Criteria
- [ ] Failed login counter increments in `users.failed_login_attempts` on each failed attempt
- [ ] Account locks after 5 consecutive failures for 30 minutes (`users.locked_until`)
- [ ] Locked account returns `423 Locked` with `locked_until` timestamp
- [ ] `POST /api/v1/auth/forgot-password` accepts email, generates reset token (32-byte random), stores in Redis with 1-hour TTL
- [ ] `POST /api/v1/auth/reset-password` accepts token + new password, validates token, updates password, clears all sessions
- [ ] Password reset token is single-use (deleted from Redis after use)
- [ ] Successful login resets `failed_login_attempts` to 0
- [ ] Login rate-limited: max 10 attempts per email per hour

## Files Affected
- `crates/gateway-auth/src/session.rs` — updated with lockout logic
- `crates/gateway-auth/src/password_reset.rs` — forgot/reset password handlers
- `crates/gateway-api/src/routes/auth.rs` — new HTTP routes
- `crates/gateway-auth/src/email.rs` — email dispatch (configurable SMTP)

## Dependencies
- TASK-0013 (JWT session authentication)
- TASK-0012 (password hashing)

## Technical Notes
- Use `redis.setex("password_reset:{token}", 3600, user_id)` for token storage
- Generate token with `rand::thread_rng().sample_iter(&Alphanumeric).take(32)`
- Email configuration via `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` env vars
- Use `lettre` crate for SMTP email sending
- New password must not match old password (check hash)

## Test Requirements

- Unit test: lockout expires after 30 minutes
- Unit test: valid reset token changes password
- Unit test: reused reset token rejected
- Unit test: new password cannot be same as old
