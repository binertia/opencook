# TASK-0057: Implement API Key Creation with One-Time Display

## Objective
Build the API key creation form with scopes, model restrictions, IP allowlist, rate limits, and the one-time full key display.

## Context
Creating an API key is a critical security action. The full key is shown exactly once and never again. See EPICS.md Epic-11.

## Acceptance Criteria
- [ ] `frontend/src/components/keys/CreateKeyModal.tsx` — creation modal
  - Name input (required, 1-128 chars)
  - Scopes multi-select: chat:write, embeddings:write, models:read, usage:read
  - Allowed models multi-select (from model registry)
  - IP allowlist input: CIDR notation (e.g., 10.0.0.0/8), multiple entries
  - Rate limits: requests/minute, tokens/minute inputs
  - Expiration date picker (optional)
  - Submit → POST /api/v1/organizations/{org_id}/keys
- [ ] `frontend/src/components/keys/KeyDisplayModal.tsx` — one-time display
  - Shows full key with copy-to-clipboard button
  - Warning: "This key will never be shown again"
  - Download as file option
  - Closes after copy or manual dismiss
- [ ] Form validation:
  - Name required, max 128 chars
  - At least one scope selected
  - IP allowlist: valid CIDR format
  - Rate limits: positive integers
  - Expiration: future date if provided
- [ ] Key creation rate-limited: max 10 keys/minute per org

## Files Affected
- `frontend/src/components/keys/CreateKeyModal.tsx` — new
- `frontend/src/components/keys/KeyDisplayModal.tsx` — new

## Dependencies
- TASK-0056 (key list page)
- TASK-0047 (API client)

## Technical Notes
- Use shadcn/ui `Dialog`, `MultiSelect`, `Input`, `Label`
- Use `react-copy-to-clipboard` or `navigator.clipboard.writeText` for copy
- Key display: use monospace font, highlight the key
- After display modal closes: invalidate key list query to show new key
- Never store full key in React state after modal closes
- Use `react-hook-form` + `zodResolver` for validation

## Test Requirements
- Create form validates all fields
- Full key displayed on creation with copy button
- Copy button copies correct key to clipboard
- Key list refreshes after creation
- Invalid CIDR format rejected
