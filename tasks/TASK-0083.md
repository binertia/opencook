# TASK-0083: Implement TLS/HTTPS Configuration and Security Headers

## Objective
Configure TLS/HTTPS support and add security headers to all HTTP responses.

## Context
Production deployments must use HTTPS. Security headers protect against common web attacks. See AUTH.md section 7 and EPICS.md Epic-17.

## Acceptance Criteria
- [ ] TLS configuration:
  - `GATEWAY_TLS_CERT` and `GATEWAY_TLS_KEY` env vars for certificate paths
  - If set: server binds with TLS (Rustls)
  - If not set: server binds plain HTTP (for reverse proxy setups)
  - Supports TLS 1.3, minimum TLS 1.2
- [ ] Security headers on all responses (via Tower middleware):
  - `Strict-Transport-Security: max-age=31536000; includeSubDomains` (HTTPS only)
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: DENY`
  - `Content-Security-Policy: default-src 'self'` (for admin UI)
  - `X-XSS-Protection: 1; mode=block`
  - `Referrer-Policy: strict-origin-when-cross-origin`
- [ ] CORS configuration:
  - `GATEWAY_ALLOWED_ORIGINS` env var (comma-separated)
  - Default: same-origin only
  - Preflight handled correctly
- [ ] Certificate hot-reload on SIGHUP (optional, nice-to-have)

## Files Affected
- `crates/gateway-api/src/tls.rs` — TLS configuration
- `crates/gateway-api/src/middleware/security_headers.rs` — security headers
- `crates/gateway-api/src/router.rs` — register middleware
- `crates/gateway-api/src/main.rs` — TLS init

## Dependencies
- TASK-0026 (Axum server)

## Technical Notes
- Use `tokio-rustls` or `rustls` crate for TLS
- Use `tower_http::set_header` layers for security headers
- Use `tower_http::cors::CorsLayer` for CORS
- Certificate files watched with `notify` crate for hot-reload
- TLS key must be PEM-encoded
- Support ACME/Let's Encrypt in future (not in this task)

## Test Requirements
- Integration test: HTTPS server responds with valid certificate
- Integration test: security headers present on all responses
- Integration test: CORS preflight succeeds for configured origins
- Integration test: CORS blocked for unconfigured origins
