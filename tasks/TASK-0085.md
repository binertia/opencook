# TASK-0085: Implement Secrets Rotation and Master Key Management

## Objective
Build the secrets rotation framework for JWT keys and encryption master keys with zero-downtime key rotation.

## Context
Secrets must be rotatable without downtime. The gateway must support active/previous key pairs. See AUTH.md section 7 and EPICS.md Epic-17.

## Acceptance Criteria
- [ ] `crates/gateway-auth/src/key_rotation.rs` — key rotation module
  - `ActiveKeyPair` struct: primary key (active), secondary key (previous)
  - JWT signing: always use primary key
  - JWT verification: try primary, then secondary (for tokens signed before rotation)
  - Grace period: secondary key valid for 24 hours after rotation
- [ ] `GATEWAY_MASTER_KEY` supports comma-separated list: `key1,key2`
  - First key: active (for encryption)
  - Second key: previous (for decryption of old data)
  - Decryption: try active first, then previous
- [ ] Key rotation procedure documented:
  1. Add new key to env var: `new_key,old_key`
  2. Restart/reload (no downtime with rolling restart)
  3. All new data encrypted with new key
  4. After 24h, remove old key: `new_key`
- [ ] JWT key rotation:
  - New private/public key pair generated
  - Old public key kept for verification during grace period
  - New tokens signed with new key
- [ ] Rotation events logged to audit log

## Files Affected

## Technical Notes
- Use `GATEWAY_JWT_PRIVATE_KEY` and `GATEWAY_JWT_PUBLIC_KEY` with comma-separated PEMs
- JWT header includes `kid` (key ID) to identify which key signed the token
- Encryption: store key ID alongside ciphertext to know which key to use for decryption
- Grace period: configurable via `GATEWAY_KEY_GRACE_PERIOD_HOURS` (default 24)
- Rotation: SIGHUP reloads keys without restart (optional)

## Test Requirements
- Unit test: token signed with old key verified during grace period
- Unit test: token signed with old key rejected after grace period
- Unit test: data encrypted with old key decryptable with new+old key pair
- Unit test: new data encrypted with new key
- Integration test: key rotation procedure works end-to-end
