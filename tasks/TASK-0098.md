# TASK-0098: Implement Audit Log Dashboard and Admin Actions Log

## Objective
Build the audit log viewer in the admin dashboard with filtering, search, and export capabilities.

## Context
Admins need to review security-relevant actions. The audit log is read-only and immutable. See EPICS.md Epic-20.

## Acceptance Criteria
- [x] `frontend/src/pages/settings/AuditLogPage.tsx` — audit log page
  - Table: timestamp, actor (user ID), action, resource type, resource ID, summary
  - Filters: action type dropdown, resource type dropdown, resource ID search
  - Pagination (client-side with server-side data)
  - Sort by timestamp (default desc from backend)
  - Export to CSV/JSON
- [x] `frontend/src/components/audit/AuditLogFilters.tsx` — filter component
  - Action type dropdown with all tracked actions
  - Resource type dropdown
  - Resource ID search input
  - Clear filters button
- [x] `frontend/src/components/audit/AuditLogDetail.tsx` — detail modal
  - Full entry JSON with copy button
  - Actor info, IP address, user agent
  - Before/after diff for update actions
  - Badge showing action type
- [x] `frontend/src/hooks/useAuditLog.ts` — audit log data hook
  - `useAuditLog(orgId, filters, limit, offset)` → GET /v1/organizations/{org_id}/audit-log
  - Supports action, entity_type, entity_id, user_id, start, end filters
- [x] Route and navigation:
  - `/settings/audit-log` route added to App.tsx
  - "Audit Log" link added to sidebar under Configure
