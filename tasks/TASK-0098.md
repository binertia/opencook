# TASK-0098: Implement Audit Log Dashboard and Admin Actions Log

## Objective
Build the audit log viewer in the admin dashboard with filtering, search, and export capabilities.

## Context
Admins need to review security-relevant actions. The audit log is read-only and immutable. See EPICS.md Epic-20.

## Acceptance Criteria
- [ ] `frontend/src/pages/settings/AuditLogPage.tsx` — audit log page
  - Table: timestamp, actor (user email), action, resource type, resource ID, details
  - Filters: action type, actor, date range, resource type
  - Search by actor email or resource ID
  - Pagination (server-side)
  - Sort by timestamp (default desc)
- [ ] `frontend/src/components/audit/AuditLogFilters.tsx` — filter component
  - Action type dropdown: all tracked actions
  - Actor search input
  - Date range picker
  - Resource type dropdown
- [ ] `frontend/src/components/audit/AuditLogDetail.tsx` — detail modal
  - Full details JSON (formatted)
  - Actor info, IP address, user agent
  - Before/after diff for update actions
- [ ] Export to CSV/JSON:
  - Export button downloads filtered results
  - Frontend CSV generation or backend endpoint
- [ ] `frontend/src/hooks/useAuditLog.ts` — audit log data hook
  - `useAuditLog(org_id, filters)` → GET /api/v1/organizations/{org_id}/audit-log
  - `exportAuditLog(format)` → export

## Technical Notes
- Use shadcn/ui `Table` with server-side pagination and sorting
- Filters: URL-synced with `useSearchParams`
- Detail modal: `Dialog` with formatted JSON
- Export: `frontend/src/lib/export.ts` with CSV/JSON generation
- Date range: default last 30 days
- Use `date-fns` for date formatting
