# TASK-0063: Implement Budget Configuration and Alert UI

## Objective
Build the budget and alerts configuration page with budget cap settings, threshold alerts, and usage progress visualization.

## Context
Budget caps prevent cost overruns. Alert thresholds notify admins when usage approaches limits. See EPICS.md Epic-12 and ROADMAP.md Phase 3.

## Acceptance Criteria
- [x] `frontend/src/pages/analytics/BudgetPage.tsx` — budget management
  - Budget cap input: monthly USD limit (or unlimited via toggle)
  - Alert thresholds: toggle switches at 50%, 75%, 90%, 100%
  - Current usage progress bar with color coding
  - Alert history: table of triggered alerts with timestamp
  - Save → updates organization settings via `useUpdateOrganization`
- [x] `frontend/src/components/budget/BudgetProgressBar.tsx` — progress bar
  - Segments: green (0-50%), yellow (50-75%), orange (75-90%), red (90-100%)
  - Shows current spend / limit with percentage
  - Animated on load (useEffect + setTimeout)
- [x] `frontend/src/components/budget/AlertHistory.tsx` — alert log
  - Table: timestamp, threshold reached, current spend, limit, notification sent, channel
- [x] Usage projection: "At current rate, you will spend $X by month end"
- [x] `frontend/src/hooks/useBudget.ts` — budget data hook
  - Fetches org settings + analytics
  - Computes progress percentage and monthly projection
  - Provides updateBudget mutation
