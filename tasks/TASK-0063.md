# TASK-0063: Implement Budget Configuration and Alert UI

## Objective
Build the budget and alerts configuration page with budget cap settings, threshold alerts, and usage progress visualization.

## Context
Budget caps prevent cost overruns. Alert thresholds notify admins when usage approaches limits. See EPICS.md Epic-12 and ROADMAP.md Phase 3.

## Acceptance Criteria
- [ ] `frontend/src/pages/analytics/BudgetPage.tsx` — budget management
  - Budget cap input: monthly USD limit (or unlimited)
  - Alert thresholds: sliders/inputs at 50%, 75%, 90%, 100%
  - Current usage progress bar with color coding
  - Alert history: table of triggered alerts with timestamp
  - Save → PUT /api/v1/organizations/{org_id}/settings
- [ ] `frontend/src/components/budget/BudgetProgressBar.tsx` — progress bar
  - Segments: green (0-50%), yellow (50-75%), orange (75-90%), red (90-100%)
  - Shows current spend / limit with percentage
  - Animated on load
- [ ] `frontend/src/components/budget/AlertHistory.tsx` — alert log
  - Table: timestamp, threshold reached, current spend, notification sent
- [ ] Usage projection: "At current rate, you will spend $X by month end"
- [ ] Budget alerts trigger webhooks and/or email (backend handles)

## Files Affected
- `frontend/src/pages/analytics/BudgetPage.tsx` — new

## Technical Notes
- Use shadcn/ui `Slider` for threshold configuration
- Use shadcn/ui `Progress` component (with custom colors)
- Projection: linear extrapolation from current daily average
- Alert history: fetch from backend (future) or local state (for now)
- Budget stored in `organizations.settings` JSONB
- Use `react-hook-form` + `zodResolver` for validation
