# TASK-0038: Implement L2 Redis Cache and Two-Tier Integration

## Objective
Build the L2 Redis cache layer and integrate L1 + L2 into a unified two-tier cache with promotion from L2 to L1.

## Context
L2 cache provides shared caching across potential future instances. On L2 hit, entries are promoted to L1 for faster subsequent access. See CACHE.md sections 1.2, 2.2.2 and EPICS.md Epic-07.

## Acceptance Criteria
- [ ] `crates/gateway-cache/src/l2_cache.rs` — L2 Redis cache
  - `get(key: &str) -> Option<CachedResponse>` — Redis GET + JSON deserialize
  - `insert(key: String, value: CachedResponse, ttl: Duration)` — Redis SETEX + JSON serialize
  - `invalidate(key: &str)` — Redis DEL
  - `invalidate_pattern(pattern: &str)` — Redis SCAN + DEL
- [ ] `crates/gateway-cache/src/two_tier.rs` — unified two-tier cache
  - `get(key)`: L1 → L2 → None (L2 hit promotes to L1)
  - `insert(key, value, ttl)`: write L2 first, then L1
  - `invalidate(key)`: remove from both L1 and L2
- [ ] Redis key format: `cache:{org_id}:{model}:{hash}`
- [ ] Configurable TTL per model (default 1 hour for GPT-4o, 24 hours for embeddings)
- [ ] `X-Cache: HIT` header on cache hit, `X-Cache: MISS` on miss
- [ ] Cache errors are non-fatal (logged, request continues)

## Files Affected

- `crates/gateway-cache/src/lib.rs` — module export and public API

## Dependencies

## Technical Notes
- Use `redis::cmd("GET")` / `redis::cmd("SETEX")` for operations
- Serialization: `serde_json::to_string` for Redis storage
- TTL configuration: model → TTL mapping loaded from DB at startup
- L2 hit promotion: `L1.insert(key, value.clone()).await` after L2 get
- Use Redis pipelining for batch operations if needed
- Handle Redis connection errors gracefully (cache becomes pass-through)

## Test Requirements
- Integration test: L2 insert + get round-trip
- Integration test: L1 miss, L2 hit → promoted to L1 → next request L1 hit
- Integration test: invalidation removes from both tiers
- Integration test: Redis unavailable → cache pass-through (no errors)
- Performance test: L2 get latency < 5ms
