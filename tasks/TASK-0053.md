# TASK-0053: Implement Add/Edit Provider Wizard

## Objective
Build the provider creation wizard and edit form for adding and configuring LLM providers.

## Context
Admins add providers by selecting the kind, entering API key, and configuring models. API keys are write-only (never shown after creation). See EPICS.md Epic-10.

## Acceptance Criteria
- [ ] `frontend/src/components/providers/AddProviderWizard.tsx` — multi-step wizard
  - Step 1: Select provider kind (OpenAI, Anthropic, Gemini, Ollama, Custom)
  - Step 2: Enter API key (input with show/hide toggle)
  - Step 3: Configure base URL (pre-filled with default, editable)
  - Step 4: Select models to enable (from known models for each provider)
  - Step 5: Configure health check (interval, timeout, model to probe)
  - Step 6: Set routing weight and priority
  - Review and submit
- [ ] `frontend/src/components/providers/EditProviderModal.tsx` — edit form
  - All fields editable except kind
  - API key shows "***" for existing; only updated if provided
  - Model enable/disable toggles
  - Test connection button
- [ ] Form validation with Zod
  - API key: non-empty, validated by backend on test
  - Base URL: valid URL format
  - Weight: 1-1000 integer
  - Priority: 1-100 integer
- [ ] `frontend/src/hooks/useProviderMutations.ts` — create/update/delete hooks

## Files Affected

## Technical Notes
- Use shadcn/ui `Dialog` for wizard modal, `Stepper` component (custom or shadcn)
- Use `react-hook-form` + `zodResolver` for validation
- API key field: type="password" with toggle to text
- Model selection: checkboxes from predefined list per provider kind
- Known models per provider: hardcoded config or fetched from backend
- Test connection: POST to backend which attempts a health check
- On success: invalidate provider cache + show success toast

## Test Requirements
- Wizard progresses through all steps
- Validation catches empty API key, invalid URL
- Edit form shows existing values, "***" for API key
- Test connection button calls backend
- Submit sends correct POST/PUT request
