# TASK-0088: Create Kubernetes Deployment Manifests

## Objective
Create Kubernetes manifests for deploying the gateway: Deployment, Service, ConfigMap, Secret, HPA, and Ingress.

## Context
Kubernetes is the primary deployment target. Manifests should follow best practices: resource limits, readiness/liveness probes, rolling updates. See EPICS.md Epic-18.

## Acceptance Criteria
- [ ] `k8s/namespace.yaml` — gateway namespace
- [ ] `k8s/deployment.yaml` — gateway Deployment
  - 2 replicas (configurable)
  - Rolling update strategy: maxSurge 1, maxUnavailable 0
  - Resource requests: 200m CPU, 256Mi memory
  - Resource limits: 1000m CPU, 512Mi memory
  - Liveness probe: `/health` every 10s
  - Readiness probe: `/ready` every 5s
  - Environment from ConfigMap + Secret
- [ ] `k8s/service.yaml` — ClusterIP service on port 80 → 8080
- [ ] `k8s/configmap.yaml` — non-sensitive configuration
  - `APP_ENV=production`, `RUST_LOG=info`
  - `DATABASE_URL`, `REDIS_URL` (from Secret instead)
  - `GATEWAY_LOG_SAMPLE_RATE`, `GATEWAY_CACHE_TTL`
- [ ] `k8s/secret.yaml` — sensitive data (template, values encrypted)
  - `GATEWAY_MASTER_KEY`, `GATEWAY_JWT_PRIVATE_KEY`, `GATEWAY_JWT_PUBLIC_KEY`
- [ ] `k8s/hpa.yaml` — Horizontal Pod Autoscaler
  - Scale 2-20 replicas based on CPU (70%) or custom metric (requests/sec)
- [ ] `k8s/ingress.yaml` — Ingress with TLS
  - Host: `gateway.example.com`
  - TLS secret reference
  - Rate limiting annotations (if ingress-nginx)

## Technical Notes
- Use `envsubst` or `kubectl kustomize` for environment-specific values
- Secrets: use `stringData` with placeholder values, never commit real secrets
- HPA: requires metrics-server in cluster
- Custom metrics: use Prometheus Adapter for request/sec scaling
- PodDisruptionBudget: ensure minimum 1 replica during disruptions
- Anti-affinity: prefer spreading across nodes

## Test Requirements
- `kubectl apply --dry-run=client -f k8s/` validates all manifests
- Deployment spec has correct resource limits
- HPA targets correct metrics
- Ingress has TLS configured
