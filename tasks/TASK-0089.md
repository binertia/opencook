# TASK-0089: Implement Zero-Downtime Deployment with Signal Handling

## Objective
Add graceful shutdown with connection draining on SIGTERM, SIGHUP for config reload, and SIGUSR1 for log rotation.

## Context
Zero-downtime deployments require graceful shutdown: stop accepting new requests, finish in-flight requests, then exit. See EPICS.md Epic-18.

## Acceptance Criteria
- [ ] `crates/gateway-api/src/shutdown.rs` — graceful shutdown handler
  - SIGTERM/SIGINT handler with `tokio::signal`
  - Stop accepting new connections
  - Drain in-flight requests (max 30s timeout)
  - Close DB pool and Redis connections
  - Exit with code 0
- [ ] `crates/gateway-api/src/config_reload.rs` — config reload on SIGHUP
  - Reloads: JWT keys, routing rules, provider configs (from DB)
  - Does NOT reload: database URL, Redis URL, master key
  - Logs reload event to audit log
- [ ] Log rotation on SIGUSR1 (optional)
  - Reopen log files if writing to files
  - No-op for stdout/stderr logging
- [ ] Kubernetes readiness probe:
  - Returns non-200 during shutdown (after drain starts)
  - Returns 200 during normal operation
- [ ] Liveness probe:
  - Always returns 200 unless process is stuck

## Files Affected
- `crates/gateway-api/src/shutdown.rs` — graceful shutdown
- `crates/gateway-api/src/config_reload.rs` — config reload
- `crates/gateway-api/src/main.rs` — signal handling
- `crates/gateway-api/src/health.rs` — readiness during shutdown

## Dependencies
- TASK-0087 (production container with signal support)

## Technical Notes
- Use `tokio::signal::unix::{signal, SignalKind}` for Unix signals
- Use `tokio::select!` to wait for either signal or normal operation
- Drain: use `tokio::time::timeout(Duration::from_secs(30), drain_fut)`
- Readiness: set atomic bool during shutdown, health endpoint reads it
- Config reload: re-read env vars, re-initialize components

## Test Requirements
- Integration test: SIGTERM triggers graceful shutdown within 35s
- Integration test: in-flight request completes during shutdown
- Integration test: readiness returns 503 during shutdown
- Integration test: SIGHUP reloads config without restarting
