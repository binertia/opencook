# TASK-0052: Implement Provider List Page with Health Status

## Objective
Build the provider list page showing all configured providers with real-time health status, latency, and error rate indicators.

## Context
Admins need visibility into all configured LLM providers and their health. See EPICS.md Epic-10.

## Acceptance Criteria
- [ ] `frontend/src/pages/providers/ProvidersPage.tsx` — provider list
  - Table: provider name, kind (OpenAI/Anthropic/etc.), status (active/inactive), health indicator
  - Health indicator: green (healthy), yellow (degraded), red (unhealthy), gray (unknown)
  - Latency column: p50 in ms, colored by threshold
  - Error rate column: percentage, red if > 5%
  - Sortable by name, health, latency
  - Filter by status (active/inactive/error)
  - Search by name
- [ ] `frontend/src/components/providers/HealthIndicator.tsx` — colored dot + tooltip
  - Tooltip shows: status, last checked, latency, error rate
- [ ] `frontend/src/hooks/useProviders.ts` — providers data hook
  - `useProviders()` → GET /api/v1/providers
  - `useProviderHealth(id)` → GET /api/v1/providers/{id}/health
  - Auto-refresh health every 30 seconds
- [ ] Manual health check trigger button per provider
- [ ] Changes propagate to routing engine within 60 seconds

## Files Affected
- `frontend/src/pages/providers/ProvidersPage.tsx` — new
- `frontend/src/components/providers/HealthIndicator.tsx` — new
- `frontend/src/hooks/useProviders.ts` — new

## Technical Notes
- Use shadcn/ui `Table` with sorting
- Health indicator: `div` with `bg-green-500`, `bg-yellow-500`, `bg-red-500`, `bg-gray-400`
- Use `@tanstack/react-query` `refetchInterval: 30000` for auto-refresh
- Latency color: < 500ms green, < 2s yellow, > 2s red
- Error rate color: < 1% green, < 5% yellow, > 5% red

## Test Requirements
- Provider list renders with all columns
- Health indicator shows correct color per status
- Sorting works on name, latency columns
