# TASK-0025: Implement Provider Health Check Framework

## Objective
Build periodic health check probes for each configured provider with status stored in Redis and accessible to the routing engine.

## Context
Health checks run every 30 seconds against each provider using a lightweight model call. Status (healthy/degraded/unhealthy) stored in Redis for fast access by routing. See EPICS.md Epic-04 and ARCHITECTURE.md section 3.2.3.

## Acceptance Criteria
- [ ] `crates/gateway-providers/src/health.rs` — health check module
  - `HealthChecker` struct with `check_provider(provider) -> HealthStatus` method
  - Makes lightweight request (e.g., list models or minimal completion)
  - Tracks latency, error rate, consecutive failures
- [ ] Background task spawned at startup to run health checks every 30s
- [ ] Health status stored in Redis: `health:{provider_config_id}` with JSON value
  - `{ status: "healthy|degraded|unhealthy", latency_ms, checked_at, error_rate_1h }`
- [ ] Circuit breaker: after 5 consecutive failures, mark `unhealthy` for 60 seconds
- [ ] Recovery: after circuit breaker timeout, attempt health check again
- [ ] `GET /api/v1/providers/{id}/health` returns current health status
- [ ] Health history stored for 24 hours (in Redis time-series or DB)

## Files Affected

## Technical Notes
- Use `tokio::time::interval(Duration::from_secs(30))` for periodic checks
- Health check uses the adapter's `health_check()` method
- Circuit breaker state: Closed (normal), Open (unhealthy, no requests), HalfOpen (testing recovery)
- Store health history as Redis sorted set: `health_history:{provider_id}` with score=timestamp
- Use `tracing` for health check logging (info on change, debug on normal)

## Test Requirements
- Unit test: healthy provider returns Healthy status
- Unit test: 5 consecutive failures triggers circuit breaker (Unhealthy)
- Unit test: circuit breaker auto-recovers after timeout
- Integration test: health check background task updates Redis
- Integration test: GET health endpoint returns correct status
