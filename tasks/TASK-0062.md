# TASK-0062: Implement API Key Usage Table with Drill-Down

## Objective
Build the API key usage analytics page showing per-key usage, cost, and token consumption with drill-down capability.

## Context
Per-key attribution helps organizations track which applications/teams are spending what. See EPICS.md Epic-12.

## Acceptance Criteria
- [x] `frontend/src/pages/analytics/KeyUsagePage.tsx` — key usage analytics
  - Table: key prefix, name, requests, tokens, cost, avg latency
  - Sortable by any column (client-side)
  - Click row → drill-down: key detail with usage over time chart
  - CSV and JSON export buttons
  - Date range selector
- [x] `frontend/src/components/analytics/KeyUsageTable.tsx` — sortable table
  - Client-side sorting with ArrowUpDown indicators
  - Cost column right-aligned with currency format
  - Responsive: table scrollable horizontally via `overflow-x-auto`
- [x] `frontend/src/components/analytics/KeyDetailPanel.tsx` — drill-down panel
  - Key info: name, prefix, status
  - Usage over time: dual-axis line chart (requests + cost)
  - Top models used by this key
  - KPI cards for requests, tokens, cost, latency
- [x] `frontend/src/hooks/useKeyUsage.ts` — hooks for key usage and drill-down detail

## Files Affected
- `frontend/src/pages/analytics/KeyUsagePage.tsx`
- `frontend/src/components/analytics/KeyUsageTable.tsx`
- `frontend/src/components/analytics/KeyDetailPanel.tsx`
