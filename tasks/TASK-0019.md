# TASK-0019: Implement Tenant Isolation Enforcement

## Objective
Ensure every repository query and admin API endpoint enforces `WHERE org_id = $1` as the first filter, with cross-organization access attempts logged and rejected.

## Context
Tenant isolation is the foundation of multi-tenancy. Every query must scope to the authenticated user's organization. Cross-org access is a security violation. See DATABASE.md section 3 and ARCHITECTURE.md section 1.3.

## Acceptance Criteria
- [ ] Base `Repository` trait in `crates/gateway-db/src/traits.rs` with `org_id` parameter on all query methods
- [ ] All repository implementations enforce `WHERE org_id = $1` as first filter
- [ ] Admin API routes extract org_id from path and validate against auth context
- [ ] Cross-organization access returns `403 forbidden` and logs to audit_log
- [ ] `AuthContext` includes `org_id` from both API key and session auth
- [ ] Every admin endpoint validates: `if auth.org_id != path_org_id → 403`
- [ ] Integration test attempts cross-org access and verifies 403

## Files Affected
- `crates/gateway-db/src/traits.rs` — base Repository trait
- `crates/gateway-db/src/repos/*.rs` — all repo files updated with org_id filter
- `crates/gateway-api/src/middleware/tenant.rs` — tenant isolation middleware
- `crates/gateway-api/src/extractors.rs` — org_id path extractor with validation

## Dependencies
- TASK-0015 (API key validation — provides org_id in AuthContext)
- TASK-0016 (RBAC — provides role-based access)
- TASK-0006 (all repository layers)

## Technical Notes
- Use Tower `Extension<AuthContext>` to propagate auth info
- Extract org_id from URL path (`/api/v1/organizations/{org_id}/...`) and validate
- Log cross-org attempts to audit_log with action=`security.violation`
- Do not rely on RLS for performance — application-level filtering is primary
- RLS is defense-in-depth for direct DB access

## Test Requirements
- Integration test: user A (org1) cannot access `/api/v1/organizations/org2/keys`
- Integration test: cross-org attempt creates audit_log entry
- Unit test: repository query includes org_id in WHERE clause (SQL inspection)
