# TASK-0042: Implement Quota Engine and Budget Caps

## Objective
Build the quota checking engine with flexible configuration: metrics (requests, tokens, cost), periods (minute, hour, day, month), and hard budget caps that reject requests when exceeded.

## Context
Quotas enforce usage limits per organization or API key. Budget caps prevent cost overruns. The quota engine checks pre-request and updates post-request. See DATABASE.md sections 2.10-2.11 and EPICS.md Epic-08.

## Acceptance Criteria
- [ ] `crates/gateway-quota/src/quota_engine.rs` — quota checking engine
  - `check_quota(context: &RequestContext, estimated_cost: f64) -> QuotaResult`
  - Supports metrics: requests, tokens, cost_usd
  - Supports periods: minute, hour, day, month
  - Actions: block (return 403), warn (allow with X-Quota-Warning header), throttle
- [ ] `QuotaResult` enum: `Allowed`, `Warning { threshold, remaining }`, `Exceeded { metric, limit }`
- [ ] Quota check query (hot path) completes in < 5ms
  - Uses `idx_quotas_org_metric_period` composite index
- [ ] Hard budget cap exceeded returns 403 with `quota_exceeded` error code
  - Zero requests pass after cap is reached
- [ ] Warning threshold (default 80%) allows request with `X-Quota-Warning` header
- [ ] Quota increment (upsert) is atomic: `INSERT ... ON CONFLICT DO UPDATE`

## Technical Notes
- Denormalize `limit_value` and `metric` in `quota_usage` to avoid JOIN on hot path
- Use `INSERT ... ON CONFLICT DO UPDATE` for atomic upsert
- Period boundaries computed with `date_trunc` equivalents in Rust
- Quota check query: single SELECT from quotas LEFT JOIN quota_usage
- Estimated cost for pre-check: `max_tokens × output_cost_per_1k / 1000`
- Scopes: all (org-wide), api_key (per-key), model (per-model), provider

## Test Requirements
- Unit test: under-limit request is allowed
- Unit test: at-limit request is blocked with 403
- Unit test: warning threshold adds X-Quota-Warning header
- Unit test: concurrent increments don't overcount (atomic upsert)
- Integration test: quota exceeded returns correct error code
