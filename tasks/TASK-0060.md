# TASK-0060: Implement Cost Dashboard with Charts and KPIs

## Objective
Build the analytics overview page with KPI cards, cost breakdown charts by provider and model, and time series trends.

## Context
Cost visibility is a primary value proposition. Dashboards show spending patterns and cache effectiveness. See EPICS.md Epic-12.

## Acceptance Criteria
- [ ] `frontend/src/pages/analytics/AnalyticsPage.tsx` — analytics overview
  - 4 KPI cards: Total Requests, Total Cost, Cache Hit Rate, Avg Latency (for selected period)
  - Time range selector: Last 24h, 7d, 30d, 90d (default 7d)
  - Cost by provider: donut/pie chart (Recharts)
  - Cost by model: horizontal bar chart
  - Cost over time: line chart (daily/hourly granularity)
  - Request volume over time: area chart
- [ ] `frontend/src/components/analytics/CostByProviderChart.tsx` — donut chart
  - Colors per provider, legend, percentage labels
  - Click to drill down to model level
- [ ] `frontend/src/components/analytics/CostOverTimeChart.tsx` — line chart
  - Dual axis: cost (USD) and request count
  - Tooltip with breakdown per day/hour
- [ ] Data accuracy: dashboard cost within 1% of sum of `usage_records.total_cost`
- [ ] Loading states for all charts

## Technical Notes
- Use `recharts` for all charts (ResponsiveContainer for width)
- Use `@tanstack/react-query` with `staleTime: 5 * 60_000` (5 min)
- Format costs: `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' })`
- Cache hit rate: `cache_hits / (cache_hits + cache_misses) * 100`
- Colors: consistent palette per provider (use Map)
- Date formatting: `date-fns` format function

## Test Requirements
- KPI cards show correct aggregated values
- Cost by provider chart renders with correct proportions
- Time range change updates all charts
- Data within 1% of backend aggregate
